# The Black Belt

Code Black's crew-health dashboard for the 2026 NASA Space Apps Challenge.

## Run and demonstrate

Open index.html in Edge or Chrome. No install or build is required. Choose an indicator in Simulated mission, then log a check-in and export your local history. Use fictional readings in public demos. Browser-local storage is unencrypted and clearing site data removes records.

## Design and current scope

The dashboard shows heart rate, wrist skin temperature, exercise minutes, sleep hours, perceived stress, and manual cuff blood pressure. Demo data is synthetic. Trends and prior averages support review. Consult the mission medical protocol for health concerns.

The proposed band combines optical pulse, motion, and contact temperature sensors. The next milestone is a physical build and comparison against reference devices. Wearable integration, device-derived sleep and stress, cuffless BP validation, and opt-in sync remain planned.

The radiation panel links to NASA's historical ISS DosTel1 archive. Importing dated measurements with their units and provenance is future work. The spacecraft environment and personal dose require separate measurements.

## GitHub and submission

Create a repository under your team account. Upload all files from this directory to the main branch. Enable [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) from the branch root for a hosted demo. Check both URLs in a private browser window.

The Bangladesh guide requests publicly accessible source and documentation with the project journey, video, and poster links. It describes a 240-second local presentation and a 30-second video for the NASA project page. Confirm the local upload process with your Local Lead. Verify the supplied video's duration and visibility before submitting it. Add the team's actual build notes and poster when available.
